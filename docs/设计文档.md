# 烈焰燎原 · 产品设计

语音咒语对战。玩家念出卡牌咒名，念得越准，效果越完整。血量先到 0 的一方落败。

| 项   | 内容                                         |
| ---- | -------------------------------------------- |
| 产品 | 可独立进行的对战游戏：学习、对电脑、玩家对战 |
| 终端 | Web；灵矽（麦克风 + 喇叭）                   |
| 本文 | 市场机会、商业价值、用户、功能与规则         |
| 另文 | 架构设计                                     |

---

## 1. 市场

家庭语音设备上的使用集中在问答、播报和闲聊，一次说完即结束。卡牌对战的需求是选角色、出牌、把对方血量打到
0，现有产品把操作放在屏幕和手上。

本产品对应的需求与打法：

| 需求                 | 市场现状               | 烈焰燎原                     |
| -------------------- | ---------------------- | ---------------------------- |
| 在语音设备上反复打开 | 没有胜负，没有再来一局 | 念咒出牌，血量到 0 结束      |
| 有可以变强的技术     | 语音交互没有完成度     | 完美、普通、未完成，效果分档 |
| 一个人能打完         | 对战依赖匹配到另一个人 | 对电脑，牌和胜负与玩家局相同 |
| 两个人坐在一起       | 需要屏幕、分屏或手柄   | 一台灵矽，声纹区分两位玩家   |
| 两个人不在一处       | 语音会话各自独立       | 四位房间号，同一局           |

Web
承担学习、对电脑和远程开房。灵矽承担学习、对电脑、同机双人和远程开房。同机双人只在灵矽上提供。

---

## 2. 目标

玩家用声音出牌，并能分出高下。

| 目标       | 玩家得到的结果                                           |
| ---------- | -------------------------------------------------------- |
| 技能可练   | 同一张牌有完美、普通、未完成三档；练习和对战用同一套判定 |
| 单人能打完 | 没有对手时，对电脑打完一整局                             |
| 两人能打   | 各用各的终端开房；或共用一台灵矽，用声纹区分谁在念       |
| 结果可信   | 血量、回合、胜负由规则给出，主持只播报，不改判           |

一局结束的条件只有这些：一方血量 ≤ 0 则另一方胜；双方同时 ≤ 0
为平局；认输或离开则对方胜；满 10 分钟为平局，不比剩余血量。

---

## 3. 商业价值

核心对局免费：学习、对电脑、联机都可以打完。付费发生在持续内容和硬件场景上。

| 对象     | 得到                   | 交换                 |
| -------- | ---------------------- | -------------------- |
| 玩家     | 练咒、对电脑、远程开房 | 免费。用时间换熟练度 |
| 玩家     | 新角色、专属牌、赛季   | 内容付费             |
| 灵矽用户 | 同机双人、喇叭主持整局 | 设备的使用场景       |

**收入**

| 来源     | 卖什么                     | 为什么成立                                         |
| -------- | -------------------------- | -------------------------------------------------- |
| 角色卡组 | 新角色及其专属牌，按季发布 | 规则不变。玩家要重新练一套咒，四条路径同时用上新牌 |
| 灵矽     | 一台设备上的双人对战       | 同机双人依赖声纹，只在该终端成立                   |
| 赛季     | 联机赛季、观战             | 建立在已经能分胜负的联机上                         |

**复购**

同一张牌的完美和普通效果不同，值得重复念。换角色即换卡组。学习、对电脑、同机双人、联机共用评级、卡组和胜负，一次内容发布覆盖全部玩法。

## 4. 用户与场景

| 用户             | 场景               | 使用方式                       |
| ---------------- | ------------------ | ------------------------------ |
| 想把咒念准的人   | 单独练习某一张牌   | 学习。Web 或一台灵矽           |
| 想马上打一局的人 | 身边没有对手       | 对电脑。Web 或一台灵矽         |
| 坐在一起的两个人 | 只有一台带麦的设备 | 灵矽同机双人。开局各录一句声纹 |
| 不在一处的两个人 | 各自有浏览器或设备 | 联机。四位房间号               |

Web 单机只有对电脑。Web
联机是玩家对玩家。灵矽单机包含对电脑和同机双人。灵矽联机是两台设备各一端。

## 5. 功能范围

| 功能       | Web | 灵矽         | 说明                             |
| ---------- | --- | ------------ | -------------------------------- |
| 学习       | 有  | 有           | 熟悉角色卡组，练习咒名，即时评级 |
| 对电脑     | 有  | 有，一台设备 | 完整对战                         |
| 同机双人   | 无  | 有，一台设备 | 声纹区分两位玩家                 |
| 联机对战   | 有  | 有，两台设备 | 开房、加入、各自选角             |
| 选角       | 有  | 有           | 战前必选，本局锁定卡组           |
| 复盘后再开 | 有  | 有           | 一局结束后可再开                 |

## 6. 主流程

```text
进入
  → 学习 | 对电脑 | 同机双人 | 联机
学习
  → 选角色 → 看卡 → 念咒 → 听到评级和该档效果 → 可转入对战
对战
  → 选角色（未选角不能准备完成）
  → 对电脑：直接准备
  → 同机双人：两人各录声纹，各自选角
  → 联机：开房或输入房间号，各自选角
  → 准备
  → 主持：三。二。一。开战。双方各30血。血量先到0的一方落败。开始念咒。
  → 多回合念咒。每记生效单独成回合，并报双方血量
  → 结算 → 复盘 → 再开一局
```

---

## 7. 学习

**目的：** 让玩家熟悉所选角色的卡牌咒语，并听清不同完成度的效果差。

**流程：**

1. 选择角色。
2. 查看该角色每张卡：咒名、法力、瞬发或吟唱、完美效果、普通效果。
3. 跟读或自己念一句。
4. 立刻听到评级和这一档的效果。
5. 可继续练，或带着该角色进入对电脑或联机。

**反馈：**

| 评级   | 玩家听到                       | 效果                 |
| ------ | ------------------------------ | -------------------- |
| 完美   | 「完美。」+ 咒名 + 完整效果    | 满额伤害、护盾或控制 |
| 普通   | 「普通。」+ 咒名 + 削弱效果    | 约七成，再取整       |
| 未完成 | 「咒语没成。」或「一次一道。」 | 不生效               |

学习不计胜负。练习里练会的那句话，进对局沿用同一判定。

可选木桩：只用于把该档伤害或护盾念出来，不进入正式对战记录。

---

## 8. 角色与卡牌

**角色**是一套卡组，不是外观。战前选择，本局锁定。本局只能念该卡组中的咒。

**卡牌**是一句咒。玩家需要看到或听到：咒名、法力、时机、完美效果、普通效果。

角色之间打法分开（爆发、控制、防御等）。新角色是新卡组，评级、吟唱、打断、胜负不变。

### 8.1 首发卡池

后续角色从这套牌里组卡，并增加该角色专属牌。

| 咒语             | 职责             | 法力 | 时机        | 冷却 | 完美                    |
| ---------------- | ---------------- | ---- | ----------- | ---- | ----------------------- |
| 火矢             | 快攻、打断、补刀 | 2    | 瞬发        | 3 秒 | 4 伤                    |
| 水幕             | 挡住下一次伤害   | 3    | 瞬发        | 8 秒 | 6 秒内挡一次，最多 8 点 |
| 寒霜止步         | 限制对手开口     | 4    | 吟唱 4.5 秒 | 8 秒 | 3 伤，禁言 3 秒         |
| 烈焰燎原         | 主要伤害         | 5    | 吟唱 6 秒   | 5 秒 | 12 伤                   |
| 九天神火焚尽八荒 | 终结             | 9    | 吟唱 8 秒   | 无   | 25 伤                   |

### 8.2 完成度

学习与对战共用。

| 情况                                                 | 评级                       |
| ---------------------------------------------------- | -------------------------- |
| 音节与咒名一致                                       | 完美                       |
| 四字咒错 1 个音节，或八字咒错 2 个音节（含长度差 1） | 普通                       |
| 两字咒（火矢）有偏差                                 | 未完成。两字咒没有普通档   |
| 一句里念出两张牌                                     | 未完成，提示「一次一道。」 |
| 对不上任何咒名                                       | 未完成，提示「咒语没成。」 |

普通档：伤害、禁言、护盾上限按约 0.7
计算后取整。战报用「擦中」「被挡住」等短句，并报双方血量。

### 8.3 资源

| 项       | 值        |
| -------- | --------- |
| 生命     | 30        |
| 开局法力 | 4         |
| 法力上限 | 10        |
| 法力回复 | 每秒 1 点 |
| 对局时长 | 10 分钟   |

念偏后约 1.5 秒不能出牌。法力不足或冷却中约 1 秒。吟唱被打断约 2
秒。打断不退还已消耗的法力。

### 8.4 吟唱与打断

| 情况                                      | 结果                                             |
| ----------------------------------------- | ------------------------------------------------ |
| 长咒                                      | 扣法力、进入冷却、开始吟唱。双方听到「开始吟唱」 |
| 瞬发打在对方吟唱上，且离结算超过 300 毫秒 | 打断。对方听到「吟唱被打断。」                   |
| 离结算不超过 300 毫秒                     | 不打断，两边都结算                               |
| 长咒对长咒                                | 互不打断，各自到时结算                           |
| 水幕                                      | 吸收下一次伤害后消失。伤被完全吸收时报「被挡住」 |

吟唱时间要长到对手能听见「开始吟唱」并念出打断用的短咒。

## 9. 对战

### 9.1 对电脑

一个玩家座位，一个电脑座位。电脑使用同一套卡牌、法力、吟唱、打断和掉血。Web
与一台灵矽均可进入。

### 9.2 同机双人

仅灵矽，一台设备。

1. 两位玩家各说一句，声纹绑定到座位甲、座位乙。
2. 各自选择角色。
3. 之后每一句咒先归属到座位，再做评级和结算。
4. 认不出说话人时，该句重念，不记到另一边。

### 9.3 联机

两个独立会话，一个四位房间号。

1. 一方开房并听到房间号。
2. 另一方说出房间号加入。
3. 各自选角、准备。
4. 双方都准备后开战。

身份按各自的会话区分。Web 对 Web、灵矽对灵矽，规则相同。

### 9.4 胜负与回合

| 条件                     | 结果                |
| ------------------------ | ------------------- |
| 一方血量 ≤ 0，另一方 > 0 | 血量大于 0 的一方胜 |
| 双方同时 ≤ 0             | 平局                |
| 满 10 分钟               | 平局                |
| 认输或离开               | 对方胜              |

生效的一击（命中、擦中、护盾张开或挡住）计 1
回合。开始吟唱、没念成、法力不足不计入回合。

---

## 10. 玩家听到什么

无独立棋盘时，主持就是对局界面。战报用连续人声说完，不使用「为您播放」一类前缀，也不把血量当成音频标题。

**开战（双方各听一次，一口气念完）：**

```text
三。二。一。开战。双方各30血。血量先到0的一方落败。开始念咒。
```

**回合示例：**

```text
第1回合。火矢命中。你30血。对手26血。
第1回合。中了火矢。你26血。对手30血。
```

**要求：**

- 一句说完再接下一句。
- 血量用句号断开：「你27血。对手30血。」
- 练习直接报「完美」或「普通」，并说出该档数值。
- 看血时报领先或落后、双方血量、当前法力。

### 10.1 灵矽上的说法

| 玩家说            | 系统回应                                     |
| ----------------- | -------------------------------------------- |
| 开始练习 / 练咒语 | 进入练习，报出可念的咒名                     |
| 一句咒名          | 练习中：评级 + 效果。对战中：出牌结果 + 血量 |
| 有哪些咒          | 咒名、法力、时机、完美与普通效果             |
| 结束练习          | 离开练习，可以开房或再练                     |
| 开房间            | 四位房间号                                   |
| 四位数字          | 加入对应房间                                 |
| 准备              | 双方齐后播放开战主持                         |
| 看血              | 领先或落后、双方血量、法力                   |
| 投降              | 本局结束，对方获胜                           |
| 复盘              | 本局过程摘要                                 |

练习不需要房间。练习只反馈评级；对战才改变血量。

---

## 11. 验收

- 新玩家能在一次使用中练会一张咒的两档效果，并打完一局对电脑。
- 同一句话在学习和对战中的评级一致。
- 未选角色不能完成准备。
- Web 可以学习、对电脑、联机；没有同机双人入口。
- 一台灵矽可以学习、对电脑、同机双人。同机双人的咒落到正确座位。
- 两台灵矽可以开房对战，两边听到开战主持和各自视角的血量。
- 只有血量到 0 才分出胜负。时间到是平局。
- 战报是连续主持，玩家能听清本回合谁掉了多少血。

---

## 12. 后续内容

在现有评级、吟唱、打断和胜负之上增加：有名字的角色与专属牌、对电脑的不同风格、练习准确率记录、观战与赛季。这些不改变第
6、7 节的规则。
