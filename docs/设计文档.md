# 烈焰燎原 · 产品设计

语音咒语对战。玩家念出卡牌咒名，念得越准，效果越完整。血量先到 0 的一方落败。

| 项   | 内容                                            |
| ---- | ----------------------------------------------- |
| 产品 | 独立的语音咒语对战游戏：学习、对电脑、玩家对战  |
| 终端 | Web（完整体验）；灵矽等智能陪伴硬件（拓展终端） |
| 本文 | 市场、目标、商业价值、用户、功能与规则          |
| 另文 | 架构设计                                        |

## 1. 市场

两股变化正在相遇。语音识别和大模型让「说一句话」足够准、足够快，可以作为游戏操作。智能陪伴硬件把带角色声音的麦克风放进了家庭和孩子身边。语音游戏缺一个让人反复开口的玩法，陪伴硬件缺一件让人反复打开的内容。烈焰燎原站在两者的交汇处。

### 1.1 语音游戏：需求长期存在，玩法稀缺

用嘴玩的游戏一直有人玩：成语接龙、猜谜、绕口令、桌游里的喊牌。需求来自三类时刻：

| 时刻             | 为什么适合语音                           |
| ---------------- | ---------------------------------------- |
| 不看屏、不动手   | 睡前、做家务、亲子陪伴时，眼睛和手被占着 |
| 几个人同处一室   | 开口就能参与，不用传手机、不用分屏       |
| 发音本身是一门技 | 普通话、背诵、绕口令，人愿意练到更准     |

过去这类游戏停在问答和测验：一问一答，没有对抗，也没有成长。识别不稳时，判定无法让人信服，对战就立不住。

现在，实时语音识别加上按音节比对，足以判断一句咒语念到了几成；大模型能把局面说成连续的主持词。语音游戏可以具备成熟品类的三个条件：

1. 操作有深度：同一句话有完美、普通、未完成，练得越准打得越重。
2. 结果可信：血量和胜负由规则结算，主持只负责播报。
3. 能对人：两个人实时念咒，互相打断，分出胜负。

同时具备这三点的语音游戏仍然很少，这是烈焰燎原进入的位置。

### 1.2 智能陪伴硬件：入口已经铺开，内容跟不上

大模型接入之后，AI
玩具、桌面陪伴机器人和带人设的音箱，从「回答问题」走向「陪着说话」。角色、性格和声音成为卖点，家长为陪伴和学习属性付费。设备的购买理由从「它能回答」变成「它在身边」。

这类设备面临同一个问题：新鲜感过去之后，开机次数下降。闲聊没有目标，问答没有结束；两个人同时在场时，设备仍然只会一对一聊天。

而一台无屏游戏主机需要的能力，这些设备已经具备：

| 游戏需要 | 陪伴硬件已有         |
| -------- | -------------------- |
| 输入     | 常开的麦克风         |
| 输出     | 喇叭和角色声音       |
| 身份     | 声纹，区分谁在说话   |
| 连接     | 联网，两台设备可互通 |

陪伴硬件下一阶段比拼的是留存，所需要的是有规则、有胜负、能多人一起玩的内容。

### 1.3 结合：语音对战成为陪伴硬件的常驻玩法

语音对战补上的，正是陪伴硬件缺的那部分：

| 陪伴硬件需要 | 烈焰燎原提供                                   |
| ------------ | ---------------------------------------------- |
| 反复被唤醒   | 一局最长 10 分钟，有胜负，结束即可再开         |
| 长期成长     | 咒语完成度和角色卡组，越练越强，有新牌可练     |
| 多人在场     | 声纹把一台麦分成两个座位，两个人在一台设备上打 |
| 角色人设     | 角色声音担任主持，报开战、出牌、血量和胜负     |
| 远程连接     | 两台设备各开一端，四位房间号联机               |

游戏也从硬件得到入口：设备已经在家里、已经开机，玩家开口即可开局，不需要另装客户端，没有屏幕也能打完。

市场按两层展开。第一层是游戏本身：在 Web
上独立运营，积累玩家、角色和赛季，内容不绑定任何机型。第二层是硬件渠道：每接入一类具备麦克风和喇叭的陪伴设备，就多一个开局入口。灵矽是第一个接入的终端，接入方式是标准的工具调用接口，可复制到其他同类设备。

## 2. 目标

### 2.1 首先是一款独立游戏

烈焰燎原是一款完整的游戏应用。玩家不连接任何硬件，在 Web
上就能学习咒语、与电脑对战、与其他玩家联机，并打完一整局。选角、评级、血量、回合和胜负都由游戏自身定义和结算。离开灵矽，产品照样成立，体验照样完整。

### 2.2 灵矽是拓展终端

灵矽是游戏接入智能硬件的第一个渠道。这类设备天然适合语音对战：

| 设备能力 | 在对局里承担       |
| -------- | ------------------ |
| 麦克风   | 出牌。念咒即出牌   |
| 喇叭     | 棋盘。主持报出局面 |
| 声纹     | 座位。区分两位玩家 |
| 角色声音 | 主持人             |

接入灵矽，规则和卡牌保持与 Web 相同。灵矽带来两样 Web
没有的东西：一台设备上的两人对战，以及由角色声音连续主持的整局。

### 2.3 要达成的效果

| 对象     | 效果                                                       | 观察口径                       |
| -------- | ---------------------------------------------------------- | ------------------------------ |
| 玩家     | 一次打开内练会一张咒，听出完美和普通的差别，并打完一局     | 首局完成率；学习转入对战的比例 |
| 玩家     | 无屏时也知道谁领先、本回合谁掉了多少血                     | 对局中途离开率                 |
| 游戏     | 只用 Web 即可完整体验；新角色一次发布进入全部玩法          | Web 独立留存；新角色练习次数   |
| 灵矽渠道 | 设备被反复唤醒；两个人一起打开同一台设备；两台设备远程对战 | 设备周对局数；同机双人开局占比 |

所有终端遵守同一条裁决：一方血量 ≤ 0 则另一方胜；双方同时 ≤ 0 或满 10
分钟为平局；认输或离开则对方胜。主持只播报结果。

## 3. 商业价值

一句话：免费打完一整局，付费买下一套要重新练的牌；硬件渠道为游戏带来不用安装的玩家，游戏为硬件带来反复唤醒的理由。

### 3.1 价值来源

| 价值         | 稀缺在哪                             | 玩家用什么交换                 |
| ------------ | ------------------------------------ | ------------------------------ |
| 熟练度       | 同一句咒的完成度决定效果成色         | 时间。重复念，换来更完整的一击 |
| 角色卡组     | 新咒的音节要重新练，打法也随之改变   | 付费购买                       |
| 可比较的结果 | 联机胜负可信，排名和观战才有内容可听 | 赛季                           |

角色是一套打法，由必须亲口念出的咒组成。玩家买到的是新的句子，以及这些句子在对局里的职责：快攻、限制、防御或终结。规则、评级和胜负保持不变，新角色因此直接进入学习、对电脑、同机双人和联机，一次发布，全部玩法同时换牌。

赛季建立在可信的胜负上。一段时间内的排名给熟练度一个比较对象；观战沿用对局主持，听众听到的就是这一局的开战、出牌和血量。

### 3.2 收入

| 来源       | 付费方   | 卖什么                               | 成立条件                           |
| ---------- | -------- | ------------------------------------ | ---------------------------------- |
| 角色卡组   | 玩家     | 新角色及专属牌，按季发布             | 新咒要重新练；四种玩法同时可用     |
| 赛季与观战 | 玩家     | 赛季排名、观战                       | 联机胜负由规则结算，结果可信       |
| 渠道合作   | 硬件厂商 | 内容接入；把设备自有角色做成联名卡组 | 对局提升设备唤醒频次和多人使用时长 |

### 3.3 灵矽渠道的价值

同机双人随灵矽提供，作为设备的玩法，计入渠道价值，不单列收费。

| 一方 | 投入                         | 得到                                                     |
| ---- | ---------------------------- | -------------------------------------------------------- |
| 游戏 | 规则、卡牌、主持词           | 已在家中开机的入口；免安装的新玩家；可做成卡组的角色形象 |
| 灵矽 | 麦克风、喇叭、声纹、角色声音 | 一件能反复打开、两人能一起玩完的常驻内容                 |
| 玩家 | 开口                         | 身边这台设备变成游戏主机，朋友家人坐下就能对战           |

账号绑定后，进度跨终端互通：在灵矽上练出的评级记录、在 Web
上购买的角色，两边都能用。硬件拿到使用时长，游戏拿到玩家，两边的留存落在同一份进度上。

### 3.4 复购

复购分三层，一层推着下一层：

| 再来一次   | 玩家感到的差别                                         | 商业上接住它                     |
| ---------- | ------------------------------------------------------ | -------------------------------- |
| 同一张牌   | 完美与普通效果不同，值得再念                           | 免费时长；形成购买新牌的意愿     |
| 下一个角色 | 新咒要重新练，职责也换                                 | 卡组付费                         |
| 下一个人   | 对电脑验证牌打得出去；对人让评级决定胜负；同机就在身边 | 联机、赛季，以及灵矽上的双人开局 |

### 3.5 成本与收费边界

| 项       | 说明                                                                               |
| -------- | ---------------------------------------------------------------------------------- |
| 内容成本 | 一张牌是咒名、数值和效果描述。新角色复用全部规则，制作集中在设计和配音             |
| 服务成本 | 评级和结算由确定规则完成；大模型负责听懂指令和主持。单局成本随语音轮次增长，可预估 |
| 渠道成本 | 按标准工具接口接入，新增一类设备复用同一套服务                                     |

| 保持免费                         | 原因                                       |
| -------------------------------- | ------------------------------------------ |
| 首发卡池、学习、对电脑、联机开房 | 玩家先打完一局，再判断下一套牌是否值得买   |
| 评级规则                         | 完美和普通的差别稳定，付费买到的始终是新牌 |
| 胜负判定                         | 血量和时间的裁决与购买无关                 |

## 4. 用户与场景

| 用户                       | 场景                         | 使用方式                       |
| -------------------------- | ---------------------------- | ------------------------------ |
| 想把咒念准的人             | 单独练习某一张牌             | 学习。Web 或一台灵矽           |
| 想马上打一局的人           | 身边没有对手                 | 对电脑。Web 或一台灵矽         |
| 家里有陪伴设备的亲子、朋友 | 坐在一起，只有一台带麦的设备 | 灵矽同机双人。开局各录一句声纹 |
| 不在一处的两个人           | 各自有浏览器或设备           | 联机。四位房间号               |

Web 单机只有对电脑。Web
联机是玩家对玩家。灵矽单机包含对电脑和同机双人。灵矽联机是两台设备各一端。

## 6. 主流程

```text
进入
  → 学习 | 对电脑 | 同机双人 | 联机
学习
  → 选角色 → 看卡 → 念咒 → 听到评级和该档效果 → 可转入对战
对战
  → 选角色（未选角不能准备完成）
  → 对电脑：直接准备
  → 同机双人：两人各录声纹，各自选角
  → 联机：开房或输入房间号，各自选角
  → 准备
  → 主持：三。二。一。开战。双方各30血。血量先到0的一方落败。开始念咒。
  → 多回合念咒。每记生效单独成回合，并报双方血量
  → 结算 → 复盘 → 再开一局
```

## 7. 学习

**目的：** 让玩家熟悉所选角色的卡牌咒语，并听清不同完成度的效果差。

**流程：**

1. 选择角色。
2. 查看该角色每张卡：咒名、法力、瞬发或吟唱、完美效果、普通效果。
3. 跟读或自己念一句。
4. 立刻听到评级和这一档的效果。
5. 可继续练，或带着该角色进入对电脑或联机。

**反馈：**

| 评级   | 玩家听到                       | 效果                 |
| ------ | ------------------------------ | -------------------- |
| 完美   | 「完美。」+ 咒名 + 完整效果    | 满额伤害、护盾或控制 |
| 普通   | 「普通。」+ 咒名 + 削弱效果    | 约七成，再取整       |
| 未完成 | 「咒语没成。」或「一次一道。」 | 不生效               |

学习不计胜负。练习里练会的那句话，进对局沿用同一判定。

可选木桩：只用于把该档伤害或护盾念出来，不进入正式对战记录。

## 8. 角色与卡牌

**角色**是一套卡组和打法。战前选择，本局锁定。本局只能念该卡组中的咒。

**卡牌**是一句咒。玩家需要看到或听到：咒名、法力、时机、完美效果、普通效果。

角色之间打法分开（爆发、控制、防御等）。新角色是新卡组，评级、吟唱、打断、胜负不变。

### 8.1 首发卡池

后续角色从这套牌里组卡，并增加该角色专属牌。

| 咒语             | 职责             | 法力 | 时机        | 冷却 | 完美                    |
| ---------------- | ---------------- | ---- | ----------- | ---- | ----------------------- |
| 火矢             | 快攻、打断、补刀 | 2    | 瞬发        | 3 秒 | 4 伤                    |
| 水幕             | 挡住下一次伤害   | 3    | 瞬发        | 8 秒 | 6 秒内挡一次，最多 8 点 |
| 寒霜止步         | 限制对手开口     | 4    | 吟唱 4.5 秒 | 8 秒 | 3 伤，禁言 3 秒         |
| 烈焰燎原         | 主要伤害         | 5    | 吟唱 6 秒   | 5 秒 | 12 伤                   |
| 九天神火焚尽八荒 | 终结             | 9    | 吟唱 8 秒   | 无   | 25 伤                   |

### 8.2 完成度

学习与对战共用。

| 情况                                                 | 评级                       |
| ---------------------------------------------------- | -------------------------- |
| 音节与咒名一致                                       | 完美                       |
| 四字咒错 1 个音节，或八字咒错 2 个音节（含长度差 1） | 普通                       |
| 两字咒（火矢）有偏差                                 | 未完成。两字咒没有普通档   |
| 一句里念出两张牌                                     | 未完成，提示「一次一道。」 |
| 对不上任何咒名                                       | 未完成，提示「咒语没成。」 |

普通档：伤害、禁言、护盾上限按约 0.7
计算后取整。战报用「擦中」「被挡住」等短句，并报双方血量。

### 8.3 资源

| 项       | 值        |
| -------- | --------- |
| 生命     | 30        |
| 开局法力 | 4         |
| 法力上限 | 10        |
| 法力回复 | 每秒 1 点 |
| 对局时长 | 10 分钟   |

念偏后约 1.5 秒不能出牌。法力不足或冷却中约 1 秒。吟唱被打断约 2
秒。打断不退还已消耗的法力。

### 8.4 吟唱与打断

| 情况                                      | 结果                                             |
| ----------------------------------------- | ------------------------------------------------ |
| 长咒                                      | 扣法力、进入冷却、开始吟唱。双方听到「开始吟唱」 |
| 瞬发打在对方吟唱上，且离结算超过 300 毫秒 | 打断。对方听到「吟唱被打断。」                   |
| 离结算不超过 300 毫秒                     | 不打断，两边都结算                               |
| 长咒对长咒                                | 互不打断，各自到时结算                           |
| 水幕                                      | 吸收下一次伤害后消失。伤被完全吸收时报「被挡住」 |

吟唱时间要长到对手能听见「开始吟唱」并念出打断用的短咒。

## 9. 对战

### 9.1 对电脑

一个玩家座位，一个电脑座位。电脑使用同一套卡牌、法力、吟唱、打断和掉血。Web
与一台灵矽均可进入。

### 9.2 同机双人

仅灵矽，一台设备。

1. 两位玩家各说一句，声纹绑定到座位甲、座位乙。
2. 各自选择角色。
3. 之后每一句咒先归属到座位，再做评级和结算。
4. 认不出说话人时，该句重念，不记到另一边。

### 9.3 联机

两个独立会话，一个四位房间号。

1. 一方开房并听到房间号。
2. 另一方说出房间号加入。
3. 各自选角、准备。
4. 双方都准备后开战。

身份按各自的会话区分。Web 对 Web、灵矽对灵矽，规则相同。

### 9.4 胜负与回合

| 条件                     | 结果                |
| ------------------------ | ------------------- |
| 一方血量 ≤ 0，另一方 > 0 | 血量大于 0 的一方胜 |
| 双方同时 ≤ 0             | 平局                |
| 满 10 分钟               | 平局                |
| 认输或离开               | 对方胜              |

生效的一击（命中、擦中、护盾张开或挡住）计 1
回合。开始吟唱、没念成、法力不足不计入回合。

## 10. 玩家听到什么

无独立棋盘时，主持就是对局界面。战报用连续人声说完，不使用「为您播放」一类前缀，也不把血量当成音频标题。

**开战（双方各听一次，一口气念完）：**

```text
三。二。一。开战。双方各30血。血量先到0的一方落败。开始念咒。
```

**回合示例：**

```text
第1回合。火矢命中。你30血。对手26血。
第1回合。中了火矢。你26血。对手30血。
```

**要求：**

- 一句说完再接下一句。
- 血量用句号断开：「你27血。对手30血。」
- 练习直接报「完美」或「普通」，并说出该档数值。
- 看血时报领先或落后、双方血量、当前法力。

### 10.1 灵矽上的说法

| 玩家说            | 系统回应                                     |
| ----------------- | -------------------------------------------- |
| 开始练习 / 练咒语 | 进入练习，报出可念的咒名                     |
| 一句咒名          | 练习中：评级 + 效果。对战中：出牌结果 + 血量 |
| 有哪些咒          | 咒名、法力、时机、完美与普通效果             |
| 结束练习          | 离开练习，可以开房或再练                     |
| 开房间            | 四位房间号                                   |
| 四位数字          | 加入对应房间                                 |
| 准备              | 双方齐后播放开战主持                         |
| 看血              | 领先或落后、双方血量、法力                   |
| 投降              | 本局结束，对方获胜                           |
| 复盘              | 本局过程摘要                                 |

练习不需要房间。练习只反馈评级；对战才改变血量。

## 11. 验收

- 不连接任何硬件，只用 Web 就能完成学习、对电脑和联机，并再开一局。
- 新玩家能在一次使用中练会一张咒的两档效果，并打完一局对电脑。
- 同一句话在学习和对战中的评级一致。
- 未选角色不能完成准备。
- Web 可以学习、对电脑、联机；没有同机双人入口。
- 一台灵矽可以学习、对电脑、同机双人。同机双人的咒落到正确座位。
- 两台灵矽可以开房对战，两边听到开战主持和各自视角的血量。
- 只有血量到 0 才分出胜负。时间到是平局。
- 战报是连续主持，玩家能听清本回合谁掉了多少血。
- 灵矽与 Web 使用同一套卡牌和判定；绑定账号后，评级记录与已购角色两端可用。
